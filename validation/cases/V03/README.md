# V03：コマンド再送と入金重複

`run.ps1`は`v03_smoke`スキーマで、コミット済みコマンドの再送が元の結果を返し、事実記録を重複作成しないことを確認します。同一コマンドキーで異なる内容を送る場合の競合、異なるキーで同じ外部入金を登録する場合の一意制約、同じキーを使う2セッションの競合も確認します。

アサーションは、再送前後の事実数・金額・コマンド受領記録、失敗時のロールバック、同時実行時のロック待ちと最終結果を比較します。実行結果はこのディレクトリの`results.json`に記録されます。

実行方法は[検証ガイド](../../README.md)を参照してください。
