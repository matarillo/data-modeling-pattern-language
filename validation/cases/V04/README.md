# V04：出荷と取消の競合

`run.ps1`は`v04_smoke`スキーマで同じ予約残数に対する出荷と取消の競合を、勝者を入れ替えて実行します。先行セッションが処理を実行したままトランザクションを保持し、後続セッションがロック待ちになる状態を観測してから先行処理を確定します。

各競合後に、在庫・受注の現在状態テーブル、事実記録、派生データの再構築結果、コマンド受領記録を照合します。敗者側の処理が部分的な事実や現在状態テーブルの差分を残さないことを期待結果と比較します。実行結果はこのディレクトリの`results.json`に記録されます。

実行方法は[検証ガイド](../../README.md)を参照してください。
