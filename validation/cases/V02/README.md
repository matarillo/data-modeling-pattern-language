# V02：過剰引当と同時実行

`run.ps1`は`v02_smoke`スキーマで、READ COMMITTEDの2セッションが同じ在庫数を読み、無防備な加算で在庫を超える制御例を作ります。その後、引当コマンドを2セッションから実行し、在庫行ロックにより一方が待機し、先行処理のコミット後に在庫不足として失敗することを確認します。

アサーションは、両方の処理が同じ在庫を観測した制御例、ロック待ちの観測、競合後の在庫・予約状態を照合します。実行結果はこのディレクトリの`results.json`に記録されます。

実行方法は[検証ガイド](../../README.md)を参照してください。
