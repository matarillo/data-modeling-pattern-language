# V01：基本フローと再構築

`run.ps1`は`v01_smoke`スキーマを初期化し、SKUの初期在庫、受注改訂、引当、出荷、残数取消、請求、入金、入金記録の訂正を実行します。期待結果と実行結果を比較し、受注・在庫・入金の状態と事実記録が一致することを確認します。

続いて意図的なSQLエラーによるトランザクションのロールバックを確認します。現在状態テーブルの値を古い値に変更し、削除してから事実記録から派生データと現在状態テーブルを再構築し、再構築後の値が元の状態に一致することも確認します。

実行方法は[検証ガイド](../../README.md)を参照してください。結果はこのディレクトリの`results.json`に記録されます。
